Data Cleaning and Preprocessing - Employee Dataset

Overview

This project focuses on cleaning and preprocessing a raw employee dataset using Python and Pandas. The goal was to identify and resolve common data quality issues, making the dataset suitable for analysis and machine learning tasks.

Tools Used

* Python
* Pandas
* NumPy
* Google Colab

Files

* `Messy_Employee_dataset.csv` – Original dataset
* `cleaned_employee_dataset.csv` – Cleaned dataset
* `Data_Cleaning_Task1.ipynb` – Data cleaning notebook

Data Cleaning Tasks Performed

* Handled missing values using median and mode imputation
* Removed duplicate records
* Standardized column names and text values
* Converted date formats to a consistent structure
* Corrected data types for age and salary columns
* Detected salary outliers using the IQR method
* Validated age values and removed invalid records

Outcome

The dataset was successfully cleaned and transformed into a structured, consistent, and analysis-ready format.
